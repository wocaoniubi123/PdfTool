PDF 页面工具（PdfTool）
======================

双击 PdfTool.exe 即可使用。pdfium.dll 必须和 exe 放在同一文件夹。

功能
----
1. 打开 PDF / 新建 PDF
   - 把 PDF 拖进窗口，或点「打开 PDF」；也可以把 PDF 拖到 exe 图标上。
   - 点「新建PDF（桌面）」直接开一个空白 PDF，保存目标就是桌面；
     把图片拖进来（或用右键菜单）即可拼页，再点「保存修改」存成 桌面\新PDF.pdf。

2. 看图翻页
   - 键盘 ← → 或鼠标滚轮上下滚，一页一页翻；
     滚得快时会用低延迟渲染先把页面显示出来，停手后自动补一张高清图。
   - 「首页 / 尾页」按钮直接跳到第一页 / 最后一页。
   - 窗口拉得越大，页面按更大尺寸重新渲染，看起来越清楚。
   - 预览按 1:1 像素绘制、渲染时做超采样，显示效果和常见 PDF 阅读器一致。
   - 中间的页码框：点一下全选，输入页码后回车，直接跳到那一页。

3. 增删改序：在图片上点右键
   - 删除本页 / 复制本页 / 上移本页 / 下移本页（调整页面顺序）
   - 提取图片到桌面：把当前页里的图片导出到桌面（一页有多张会依次编号）。
     · JPEG / JPEG2000 图：**按 PDF 里存的原始字节原样导出**（不重编码，逐个文件与
       PDF 内部数据核对过，逐字节一致）；
     · 其它压缩格式（如调色板/Flate 图）：解码成 PNG，画质无损不重压缩；
     · 自己插入的图片页：原样导出原文件字节。
     说明：程序自己解析 PDF 取原始数据（pdfium 拿不到原始字节）。
     支持：JPEG / JPEG2000 原样导出；Flate 与调色板图无损解码成 PNG；
     ASCII85/ASCIIHex 前置编码的图；CCITT 传真图导出为 TIFF（Windows 照片可开）；
     JBIG2 导出 .jb2；以及"对象流 + xref 流"结构的新式 PDF。
     仍认不出的结构会自动退回 pdfium 解码，不会出错，只是那种图可能被折算分辨率。
   - 在上面 / 在下面插入图片：弹出文件选择框（可多选）插进来；
     直接把图片文件拖到窗口里也可以插入：拖进来的图插在**当前页之前**，
     一次拖多张时按拖入顺序排列（没有打开文档时会自动新建一个空白 PDF）。
     （支持 jpg / png / bmp / gif / tif；JPEG 原图直嵌不重压缩；
     其它格式按解码后的像素无损嵌入，**PNG 的透明区域也会保留**（用 SMask）；
     插入的图片会按当前页面大小居中缩放）
   - 注意：改动只在内存里，点「保存修改」才会写盘。

4. 保存修改
   - 另存为 <原名>_已修改.pdf，放在原 PDF 所在文件夹，原文件不动。
   - 保存/拆分是在**原文件的副本上**删页、移页、插页：所以原文件的**书签、文档属性、
     表单域都会保留**，页面里的图片数据也是逐字节原样（不重编码）。

5. 拆分奇数/偶数页
   - 生成 <原名>_奇数页.pdf 和 <原名>_偶数页.pdf，同样放在原 PDF 所在文件夹。
   - 同名文件会先问：覆盖，还是自动加 (2) 序号。
   - 先增删页再拆分也可以：拆出来的是你改过的页序。

命令行（可选）
--------------
PdfTool.exe --split "文件.pdf"      直接拆奇偶页，不弹界面
PdfTool.exe --selftest "文件.pdf"   自检：删页/复制/插图片后另存，再回读逐页比对
PdfTool.exe --rendump 文件.pdf 页码 宽度 输出.png   把某页渲染成图片（调试用）

重新编译
--------
双击 build.bat（用 Windows 自带的 C# 编译器，不需要装 Visual Studio 或 SDK）。

目录说明
--------
开发日志.md     开发/修复记录与待办（交接用）
src/            源代码（C#，WinForms）
build.bat       编译脚本
PdfTool.exe     编译产物（图标已内嵌）
app.ico         程序图标（红字 PDF）
mkicon.py       重新生成图标的脚本（python mkicon.py）
pdfium.dll      渲染与读写 PDF 的内核（PDFium，BSD 许可）
include/         PDFium 开发头文件
licenses/ LICENSE VERSION   PDFium 的许可证与版本
